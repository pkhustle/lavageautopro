Executive Summary

The site has a solid Next.js foundation, clear service intent, and broad local page coverage. The main risk is not content volume; it is inconsistent technical signaling.

Critical

Robots file is missing

Evidence-Based Findings

Findings are labeled by impact and confidence.

Critical

Serve a real robots.txt file

Googlebot can still crawl without a robots file, but a missing robots file is a poor crawl management signal, especially for a site with 206 sitemap URLs and many templated local pages.

GET https://www.lavageautointerieur.ca/robots.txt -> HTTP 404, content-type text/html; x-matched-path: /[service]

Fix: add public/robots.txt or app/robots.ts with allowed crawling and a sitemap line pointing to the canonical sitemap URL.

Critical

Align canonical domain, sitemap, and redirects

Every sampled sitemap URL uses https://lavageautointerieur.ca, but production redirects that host to www. Live pages then declare non-www canonicals. Choose one canonical host.

https://lavageautointerieur.ca/ -> 308 -> https://www.lavageautointerieur.ca/ while homepage canonical is https://lavageautointerieur.ca

Fix: either stop redirecting to www, or update SITE_CONFIG.url, canonical generation, Open Graph URLs, and sitemap generation to use https://www.lavageautointerieur.ca.

High

Add homepage and contact structured data

Service and location pages output JSON-LD, but homepage, services index, and contact page have no JSON-LD. Local service businesses should make identity, address, service area, hours, and contact data machine-readable.

Homepage JSON-LD count: 0. Contact page JSON-LD count: 0. Service page JSON-LD count: 2. Location page JSON-LD count: 6.

Fix: add Organization/LocalBusiness schema sitewide, WebSite schema on the homepage, BreadcrumbList on key pages, and Service schema for the services overview.

High

Strengthen titles for commercial intent

Several service titles are very short and omit brand, location, or buyer modifiers. This is a missed CTR and relevance opportunity.

/lavage-auto-interieur title length: 21. /lave-auto-a-la-main title length: 19. Homepage title length: 62.

Fix: use templates like "Lavage auto intérieur à domicile au Québec | Lavage Auto Pro" and "Lave-auto à la main professionnel | Québec".

Medium

Fix escaped apostrophes in metadata

Some meta descriptions output &amp;apos; instead of a normal apostrophe. This can look unpolished in snippets and signals that metadata is being escaped twice.

Service description includes "d&amp;apos;entretien" and "l&amp;apos;habitacle" in rendered meta content.

Fix: store plain apostrophes in constants, not HTML entities, and let React/Next escape output.

Medium

Improve local page uniqueness and French localization

The site generates 200 service-location pages. This can work, but it needs unique local proof to avoid doorway-page patterns.

Sample H1: "Lavage auto intérieur à Montreal". Sitemap contains 206 URLs. Location constants normalize accents away.

Fix: use proper French names such as Montréal, Québec, Lévis, Trois-Rivières, Saint-Jérôme, Côte-Saint-Luc, Val-d'Or, Sept-Îles, and L'Assomption. Add local testimonials, service-area notes, travel radius, and locally specific FAQs.

High

Add an AIO/GEO content layer

AI Overviews and answer engines reward concise, extractable answers, entity clarity, structured FAQs, and authoritative citations. Current pages are service-forward but not especially citation-ready.

/llms.txt -> HTTP 404. Homepage has no JSON-LD. No obvious source/citation blocks or concise answer-first sections were found.

Fix: add answer-first blocks, comparison tables, "how much does it cost" answers, process definitions, FAQ schema where eligible, and an llms.txt overview for AI crawlers.
